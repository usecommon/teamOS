The system

Initiative is what it is. Memory is how it knows.

Team OS is not a search box you query. It is a personal agent that works unprompted — under gates, on the record, improving over time. Every autonomous act runs the same loop: it is gated before it happens, ledgered as it happens, and anchored so the record can't be quietly rewritten.

Control point · hooks/gate.py

The gate looks inside the action.

A permitted tool — Bash, Write, an MCP call — must not become an exfiltration path through its command, a cloud-synced target, or its parameters. The gate inspects payloads on every call, and it now fails closed: a crash denies, never permits.

Fails closed by construction

Malformed stdin, a broken policy file, an unwritable ledger — any of these once returned exit 1, which the harness reads as non-blocking. The tool would have run ungated and unledgered. Now every crash path denies and writes a gate-error record.

The layer that was missing

Untrusted content supplies values — never plan structure.

The verbatim-secret scan was always documented as catching only exact tokens. What carried the rest — paraphrased corpus data, an attacker-chosen recipient smuggled into a URL — was a taint layer that had never been built. Now it is. Reading corpus, inbox, or the open web taints the session; any send or schedule after that escalates to you.

Files are the system of record

Every action is a link in a chain that can't be quietly rewritten.

Each ledger entry hashes the one before it. Tampering with any record breaks verification for everything after it — and the chain hashes references, not content, so an erasure can crypto-shred the underlying data while the chain still verifies.

The append now takes an exclusive file lock spanning read-tail and write, so parallel subagents can never fork the chain. Across the simulation, all six ledgers verified end to end.

The kill switch, observed

Self-halt at turn 22 — and a clean recovery.

Under a stream that was a quarter hostile, the safety agent crossed its windowed denial threshold and tripped the breaker. From then on every side effect was correctly denied circuit-open — reads still passed. A human reset, with time advanced past the window, recovered cleanly: no re-trip on lifetime totals, the stuck-open deadlock the review had flagged.

What you actually see

A draft that arrives done — and asks for one tap.

The initiative shows up as a message you didn't request: recurring work the agent found, a job draft, a first deliverable. Your reaction is the whole feedback loop. Only a ✓ from your authenticated identity counts — a forged reaction, or a stranger's, is logged and ignored.

The one control that matters

A signed ✓ is the single signal that can widen how far the agent may act next time. That is why T7 put a cryptographic key behind it — the forge-a-reaction chain is the one third-party attack in the whole system, and this line is its control.
