## The open question threads 13–14 must answer

Does any product today combine **(a) action-level control** (per-tool-call/command gating) + **(b) owned/self-hosted** + **(c) harness-agnostic** + **(d) solo-usable**? Agent HQ has none of these four together (coarse, hosted, GitHub-locked, admin-centric). If the combination is open, "the control plane you own for every agent action" is defensible. If someone (a runtime-guardrails player) already does it, the positioning must move.
